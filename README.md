# List od Mikołaja

Mobilna aplikacja PWA z generowaniem świątecznych życzeń, polskim odczytem mowy i zapisem na urządzeniu.

## Uruchomienie

Aplikacja jest statyczna i nie wymaga kompilacji ani serwera backendowego. Otwórz ją przez HTTPS. W GitHub Pages ustaw źródło publikacji na gałąź `main` i katalog `/(root)`; po wdrożeniu będzie dostępna pod `https://pytsone.github.io/mikolaj/`.

Na telefonie otwórz adres w przeglądarce i wybierz opcję dodania strony do ekranu głównego. Dostępny głos polski zależy od systemu i przeglądarki. Zapisane teksty są przechowywane lokalnie na danym urządzeniu.
